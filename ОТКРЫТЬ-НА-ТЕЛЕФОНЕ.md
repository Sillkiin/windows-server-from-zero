# Windows Server на телефоне

Открой в Safari: https://sillkiin.github.io/windows-server-from-zero/

«Поделиться» → «На экран “Домой”» → «Добавить». После первого полного открытия основные материалы сохраняются для офлайн-запуска. Внешним ссылкам Microsoft нужен интернет.

Начни с блока «Сервер и маленький офис». Для конкретной задачи: «Уроки» → «Что и где добавляется». В каждом блоке нажми «Смотреть», затем «Как сделать по шагам».

Полная инструкция: https://sillkiin.github.io/windows-server-from-zero/manual.html

PDF: https://sillkiin.github.io/windows-server-from-zero/WINDOWS_SERVER_RU.pdf

Прогресс хранится на устройстве. Для переноса: «Уроки» → «Мой прогресс» → «Скачать прогресс».
