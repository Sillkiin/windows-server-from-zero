# Учебник Windows Server на телефоне

Открой в Safari: https://sillkiin.github.io/windows-server-from-zero/

Начни с блока «Сервер и маленький офис». Прочитай «Перед началом», посмотри обе сцены и раскрой пошаговую инструкцию. С телефона можно пройти весь материал; настоящая практика выполняется на компьютере внутри ВМ.

Для установки ярлыка: «Поделиться» → «На экран “Домой”» → «Добавить». Основные уроки сохраняются после первого полного открытия с интернетом. Для новой версии: «Уроки» → «Обновить учебник». Если открыта старая версия без этой кнопки, обнови страницу при наличии интернета и открой её снова после сохранения новой копии.

Прогресс хранится в этом браузере. Для переноса: «Уроки» → «Мой прогресс» → «Скачать прогресс», затем «Загрузить прогресс» на другом устройстве.

Полная инструкция: https://sillkiin.github.io/windows-server-from-zero/manual.html
