**[Открыть учебник](https://sillkiin.github.io/windows-server-from-zero/)** · [Полная инструкция](https://sillkiin.github.io/windows-server-from-zero/manual.html) · [PDF, 46 страниц](https://sillkiin.github.io/windows-server-from-zero/WINDOWS_SERVER_RU.pdf)

Русскоязычный курс для новичка: 18 блоков, 36 анимированных сцен, 18 упражнений, 54 вопроса, итоговые подходы по 15 вопросов, 8 командных миссий и 46 объяснений терминов.

Темы: версии и установка Windows Server, изолированная лаборатория, начальные настройки, AD DS, DNS, DHCP, OU/пользователи/группы, ввод компьютеров в домен, диски, общие папки и права, GPO, резервное копирование, удалённое управление, службы/журналы/обновления, печать/IIS/RDS, Hyper-V и диагностика.

В каждом блоке: понятный пример, движение между участниками, пошаговая инструкция с меню и командами, упражнение и микротест. Раздел «Что и где добавляется» помогает быстро найти нужную задачу.

## На iPhone

1. Открой ссылку в Safari с интернетом.
2. Нажми «Поделиться» → «На экран “Домой”» → «Добавить».
3. После первого полного открытия основные уроки и инструкция сохраняются для офлайн-запуска. Внешние ссылки Microsoft требуют сети.

Меню «Уроки» открывает курс, лабораторию, тренировку, словарь и прогресс. Разметка, команды и схемы помещаются по ширине телефона. Результаты хранятся только в браузере. Раздел «Мой прогресс» экспортирует и импортирует JSON для переноса на другое устройство.

## Без сайта

Открой index.html в обычном настольном браузере: стили, содержание и программа встроены в HTML. Рядом manual.html — полная инструкция без зависимости от JavaScript; WINDOWS_SERVER_RU.md и WINDOWS_SERVER_RU.pdf — варианты для чтения и печати. Для телефона удобнее опубликованная версия.

## Границы

Основной пример — Windows Server 2025 Standard Desktop Experience; базовые действия подходят и для 2022 с учётом различий. Адреса, имена и ответы командной лаборатории учебные. Сайт не выполняет команды ОС и не подключается к серверам. Настоящие Windows Server, AD, физический принтер и RDS при подготовке учебника не развёртывались. Проверка в WebKit использует браузерную эмуляцию, физический iPhone не участвовал.
