# Windows Server с нуля

**[Открыть учебник](https://sillkiin.github.io/windows-server-from-zero/)** · [Полная инструкция](https://sillkiin.github.io/windows-server-from-zero/manual.html) · [PDF, 66 страниц](https://sillkiin.github.io/windows-server-from-zero/WINDOWS_SERVER_RU.pdf)

Русскоязычный курс: 18 блоков, 36 анимированных сцен, 18 упражнений, 54 вопроса, итоговые подходы по 15 вопросов, 8 командных миссий и 66 объяснений терминов.

15 ноября 2026 года весь материал повторно отредактирован для первого знакомства с администрированием. В каждом блоке есть «Перед началом»: задача, нужная машина и учётка, подготовка и ожидаемый результат. В первом блоке объяснены Win+R, PowerShell, локальные и сетевые пути, IP-адрес, маска, шлюз и порт. Основной маршрут проходит через домен, адреса, учётные записи, общую папку, политику и проверенное восстановление файла.

Курс можно читать с телефона без серверов. Практика в браузере — имитация. Настоящие настройки выполняют отдельно в новых учебных ВМ. Выбирай один способ настройки: мышкой или PowerShell; соответствующее создание объекта повторять обоими способами не нужно. Команды проверки выполняются после выбранного способа.

## На телефоне

1. Открой ссылку в Safari с интернетом. Начни с «Сервер и маленький офис».
2. В блоке прочитай «Перед началом», посмотри обе сцены, раскрой инструкцию, попробуй упражнение и три вопроса.
3. Для удобного запуска: «Поделиться» → «На экран “Домой”» → «Добавить». После первого полного открытия основные материалы сохраняются для офлайн-запуска. Внешним ссылкам Microsoft нужен интернет.
4. Для новой версии: «Уроки» → «Обновить учебник». Обновление старой версии с сохранением прогресса проверено в Chromium и WebKit.

Меню «Уроки» открывает блоки, указатель «Что и где добавляется», лабораторию, тренировку, словарь и прогресс. «Мой прогресс» позволяет скачать JSON и объединить его с результатами на другом устройстве. Прогресс привязан к браузеру и адресу сайта.

## Материалы в папке

index.html — интерактивная часть, manual.html — подробная инструкция; WINDOWS_SERVER_RU.md и WINDOWS_SERVER_RU.pdf — текст и печатная версия. Оба HTML работают из локальной папки в настольном браузере. Телефону удобнее опубликованный адрес.

Редакторские изменения: ПОНЯТНОСТЬ-ДЛЯ-НОВИЧКА.md. Проверки: ПРОВЕРКА.md и JSON-отчёты рядом. Официальные источники: sources.json.

## Границы

Пример — Windows Server 2025 Standard Desktop Experience, базовые действия применимы к 2022 с учётом различий. Учебная сеть отдельная, без маршрутизатора. Все адреса и имена условные. Сайт не выполняет команды ОС и не подключается к серверам.

Настоящие Windows Server/AD, физический принтер и RDS при подготовке не развёртывались. Проверка PowerShell — синтаксический разбор, не исполнение. Chromium/WebKit проверены в браузерной эмуляции, физический iPhone не участвовал. Понятность оценена редакторским проходом по всем материалам; испытания с отдельным участником-новичком не проводились.
