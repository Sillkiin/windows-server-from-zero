# Windows Server с нуля

Открой **index.html** — это интерактивный курс. Рядом **manual.html** — полная инструкция с меню, командами, проверками и печатью. Оба HTML содержат основные стили и данные внутри и работают из локальной папки без интернета.

В курсе 18 блоков, 36 анимированных сцен, 18 упражнений, 54 вопроса, итоговые подходы по 15 вопросов, 8 командных миссий и словарь. Прогресс хранится в браузере. «Мой прогресс» позволяет скачать его и перенести на другое устройство.

На iPhone удобнее открывать опубликованную HTTPS-версию в Safari. Для размещения подходит GitHub Pages: загрузить содержимое этой папки в отдельный публичный репозиторий и включить Pages для нужной ветки. В этой поставке публикация не выполнялась. После размещения: Safari → Поделиться → На экран «Домой». Для офлайн-режима нужно первое полное открытие с интернетом. На HTTPS и localhost работает service worker; из file:// регистрация не требуется.

Подписи окон основаны на Desktop Experience. Основной пример: Windows Server 2025, базовые действия подходят для Server 2022 с учётом различий. Все ВМ, имена, пользователи и ответы лаборатории учебные. Материал не запускает команды ОС, не читает пароли и не подключается к серверам. Для реальной практики предусмотрена отдельная изолированная лаборатория.

Официальные источники: sources.json. Проверки интерфейса и их ограничения: ПРОВЕРКА.md и verification.json после завершения проверки. Реальная установка Windows Server и работа физических устройств не выполнялись.

Полная инструкция для чтения и печати: **WINDOWS_SERVER_RU.pdf**, 46 страниц. Иллюстрации интерфейса: preview-desktop.png и preview-phone.png.
