# Проверка понятности для новичка

Дата: 15 ноября 2026 года. Версия: 2026.11.15.2.

Проверены все 18 блоков, 36 сцен с 144 репликами, 18 упражнений, 54 вопроса с пояснениями, 8 командных миссий, словарь и переходы между материалами. Это редакторская оценка и проверка интерфейса, а не измерение понимания на группе новичков.

## Что изменено

| Место | Как теперь объясняется |
|---|---|
| Все блоки | Видны задача, машина, учётка, подготовка и конкретный результат; есть переходы к необходимым урокам. |
| Первое знакомство | Отдельно объяснены браузерный тренажёр и работа в ВМ, последовательность курса и выбор одного способа настройки. |
| Окна и команды | Показано, как открыть Win+R и Windows PowerShell, где выполнить hostname/whoami и как действовать при первой ошибке. |
| Адреса и пути | Разобраны IP, /24, DNS, шлюз, порт, локальный путь, UNC и доменное имя входа. |
| Установка | Добавлен конкретный маршрут создания ВМ в Hyper-V; явно нужны две установки Server и отдельная клиентская Windows. |
| Начальные настройки | Объяснены промежуточный адрес 169.254.x.x до DHCP, маска/префикс и перезагрузка после имени. |
| AD DS | Добавлен явный ввод LAB в NetBIOS domain name и объяснено, какой пароль используется после первого повышения. |
| DNS | Первая проверка выполняется на DC1, потому что PC1 ещё может не иметь DHCP-адреса. Добавлены ожидаемый ответ и варианты ошибок. |
| DHCP | Показаны авторизация, автоматические IPv4/DNS на PC1 и конкретные поля ipconfig /all. |
| Учётные записи | Расшифрованы GG/DL/Accounting/Modify, уточнены Members и Member Of, новые OU отделены от стандартных контейнеров. |
| Доменное членство | Явно добавлены присоединение FS1, подходящая учётка, перемещение объектов в OU и проверка входа Анны. |
| Диски | Объяснены диск, том, буква и папка; показано создание Shares/Accounting и замена буквы во всех последующих путях. |
| Общая папка | Расписаны роль File Server, NTFS и SMB-разрешения, адресная строка Проводника и отрицательная проверка под test.reader. |
| Политики | Раскрыты оба поля сообщения перед входом, открытие HTML-отчёта и дополнительный пример сетевого диска P:. |
| Копии | Файл создаётся до копирования; определены отдельный учебный диск назначения, папка восстановления и сравниваемый текст. |
| Удалённый доступ | Соединение показано с PC1 на FS1 внутри Private-сети; различены выход из сеанса и закрытие окна RDP. |
| Обслуживание | Первый опыт — прочитать DNS Server и одно событие; переведены Status, Startup type, trigger и action. |
| Дополнительные роли | IIS можно проверить на учебном FS1; принтер и RDS явно требуют отдельной подготовки. |
| Hyper-V | Различены хост и гости; уже созданные ВМ не предлагается пересоздавать. |
| Диагностика | Дана цепочка ожидаемых ответов и значение True/False для конкретного теста. |
| Итог | Предложен простой протокол доказательств; принтер, RDS и второй DC не обязательны для основного маршрута. |
| Сцены, задания, словарь | Исправлено отображение обратных слешей, убраны шуточные отвлекающие ответы, словарь расширен до 66 терминов. |
| Телефон и обновление | Проверены раскрытые тексты на узком экране и реальное обновление старого service worker с сохранением результатов. |

Сложные дополнительные упражнения раскрываются отдельно. В полной инструкции и PDF они сохранены для последующего изучения. Полного развёртывания RDS, AD CS, отказоустойчивого кластера или миграции рабочего домена этот курс не обещает.

## Что ещё должен подтвердить учащийся

На собственных ВМ нужно отдельно подтвердить реальные окна, установку, вход, выдачу адресов, доступ к файлам, применение GPO и восстановление. Материал сверялся с документацией Microsoft, но здесь Windows Server не запускался. Для проверки обучения с человеком полезно пройти первые шаги без подсказок автора и записать, на каком слове или действии потребовалась помощь.

Дополнительная сверка уточнённых маршрутов: [создание ВМ Hyper-V](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/get-started/create-a-virtual-machine-in-hyper-v) и [создание первого домена, Additional Options](https://learn.microsoft.com/en-us/windows-server/networking/core-network-guide/core-network-guide). Подходящие разделы прочитаны через MicrosoftDocs/Context7; ограничения старых примеров PowerShell не перенесены в процедуру для Server 2025.
